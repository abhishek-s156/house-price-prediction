-> House Price Prediction 🏠
Machine Learning project to predict house prices using California Housing Dataset.

-> Accuracy
- Linear Regression: 60%
- Random Forest: 80%
- XGBoost: 83% (Best Model)

-> Tech Stack
Python, Pandas, Scikit-Learn, XGBoost, Matplotlib, Seaborn

-> Dataset
California Housing Dataset from sklearn.datasets

-> How to Run
1. Open notebook in Google Colab
2. Run all cells
3. Model will predict price on new data
